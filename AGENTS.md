# Работа с интерфейсом

## Вход в проект для нового агента

Перед первой задачей прочитать `agents/README.md` и `agents/PROJECT_CONTEXT.md`. Для Android также прочитать `agents/ANDROID_HANDOFF.md`, `ANDROID_PACKAGING_PLAN.md` и актуальные записи `mobile/PORT_STATUS.md`. Это переносимый контекст репозитория; история чата на другом компьютере может отсутствовать.

Сначала проверить текущую ветку и `git status`, не затирать чужие изменения. Документы описывают состояние на указанную дату: при расхождениях сверять исходники и явно отмечать найденные отличия. После работы обновлять соответствующую документацию и передавать следующему разработчику выполненные проверки, ограничения и следующий шаг. Эти инструкции не разрешают сами по себе запуск публикации, подключение платных сервисов или реализацию всего списка будущих задач.

## Стабильная база

По указанию пользователя от 21.11.2026 версия 5.5.0 считается стабильной. См. STABLE_RELEASE.md. Не менять игровые механики, баланс, контент и UI без новой отдельной задачи. Текущая работа — Android-перенос по ANDROID_PACKAGING_PLAN.md; изменения совместимости и выполненные шаги записывать в mobile/PORT_STATUS.md. Не путать стабильную веб-базу с завершённой приёмкой Android.

Перед изменением UI прочитать `UIdata.md` и сверить относящиеся к задаче размеры, цвета, шрифты, состояния и адаптивные правила с актуальными исходниками.

После изменения UI обновить соответствующие разделы `UIdata.md`, включая затронутые таблицы токенов и снимки CSS. Документ описывает реализованный интерфейс: если он устарел, уточнить его по коду, а не отменять актуальные изменения ради старой описи.

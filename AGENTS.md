# Работа с интерфейсом

Перед изменением UI прочитать `UIdata.md` и сверить относящиеся к задаче размеры, цвета, шрифты, состояния и адаптивные правила с актуальными исходниками.

После изменения UI обновить соответствующие разделы `UIdata.md`, включая затронутые таблицы токенов и снимки CSS. Документ описывает реализованный интерфейс: если он устарел, уточнить его по коду, а не отменять актуальные изменения ради старой описи.

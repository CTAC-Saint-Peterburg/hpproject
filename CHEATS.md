# Отладка и управление
Версия 2.0.0. Клавиши работают по физическому коду независимо от раскладки, без повтора при удержании. В полях ввода отключены, кроме F10 и закрытия меню читов по Esc.

## Меню читов (1.3.0)
F10 открывает/закрывает общее окно в стиле trainer в главном меню, мастерской и на арене. Нажмите кнопку конкретного чита: действие выполняется сразу, результат показан внизу. Повторные нажатия повторяют действие. F10/Esc или «Закрыть» скрывают окно; Esc при открытом окне не выводит из игры. Tab/Shift+Tab переключают кнопки внутри окна. Игра и таймер продолжаются.

Доступны +100/−100 stones, добавление по одному зелью каждого типа в постоянное хранилище (вне арены), переключение FPS, нагрев/охлаждение, левитация, пропуск этапа, отдельные кнопки спавна каждого врага мастерской и арены, выбор и запуск любой волны 1–10. Недоступные в текущем режиме кнопки серые. При заполненном лимите спавн не сработает; сначала освободите место. Правила debug и наград те же, что у соответствующих хоткеев. Открытие окна само по себе награды не отключает. Предыдущие хоткеи, макросы и F9 на арене сохранены.

| Клавиша | Действие |
| --- | --- |
| F8 | Переключить FPS: цифры в чёрном квадрате. Измеряется в 3D-сцене; в меню последнее значение. |
| Alt + Shift + = | Добавить 100 stones, также в меню. |
| Alt + Shift + - | Вычесть 100 stones, минимум 0. |
| Alt + Shift + ↑ | Усилить огонь на 1, максимум 3. |
| Alt + Shift + ↓ | Уменьшить огонь на 1, минимум 0. |
| Alt + Shift + L | Включить левитацию без жеста. |
| Alt + Shift + N | Пропустить этап; награды, рекорды и достижения отключаются до следующей попытки. |
| Esc | Прервать миссию и выйти в меню. |
| P | Пауза/продолжение варки; также доступна кнопка «Пауза». |

Обычное управление: клик по котлу выбирает его. V-жест (1) усиливает огонь, замкнутый квадрат (2) ослабляет, круг (5) помешивает. Температура меняется постепенно. Кликните куб, затем нарисуйте вертикальную линию (3), чтобы поднять его, и подведите к центру котла. Горизонталь (4) отпускает куб. При контакте куб автоматически поднимается, уменьшается с магическим эффектом и падает внутрь; условия рецепта проверяются в конце полёта. На исходном месте плавно появляется замена. После ошибки выберите новый куб и повторите перенос. Во время паузы полёт и появление куба остановлены.

Старые + / - для перемотки рецепта отключены.

## Вызов врагов (0.8.0)
| Хоткей | Действие |
| --- | --- |
| Alt + Shift + 1 (верхний ряд) | Вызвать синего enemycold. |
| Alt + Shift + 2 (верхний ряд) | Вызвать жёлтого enemyfire. |

Только во время активной миссии. Можно вызвать любой тип независимо от конфига уровня. Одновременно максимум два врага; если оба угла заняты, сначала уничтожьте одного. Успешный принудительный спавн помечает попытку как отладочную: stones, рекорды и достижения за неё не начисляются. Новая попытка снимает эту отметку.

Выберите врага кликом (белая обводка), затем нарисуйте V против синего или замкнутый квадрат против жёлтого. Попадание снаряда изменяет температуру на −15/+15 °C.

## Обучение (0.9.0)
Открывается кнопкой «Обучение заклинаниям» в меню. Обведите образец от золотой точки по стрелке, не отпуская кнопку мыши/палец. Успешный рисунок засчитывается после отпускания. Нужно по два повтора каждого из десяти жестов. Прогресс сохраняется; «Очистить» стирает только текущий рисунок. Прохождение необязательно: можно сразу играть. Отдельные читы для прогресса обучения не добавлены.

## Языки (0.10.0)
Меню → «Язык»: русский, English, 中文, Español, Français. Переключение не сбрасывает прогресс; выбор сохраняется после перезагрузки. Горячие клавиши одинаковы во всех языках и раскладках. Словари находятся в src/translate/*.json. Отдельного хоткея для смены языка нет.

## Эффекты (0.11.0)
Рисуйте жесты в игре: каждый распознанный жест меняет след палочки и создаёт цветную вспышку. Выберите котёл для вспышки на котле либо врага и примените правильное контрзаклинание для вспышки на враге. Повтор того же жеста повторяет эффект. Alt + Shift + L позволяет проверить эффект левитации без рисования. Параметры цветов, скоростей, количества, времени жизни и вспышек: src/static/spellEffects.json. Отдельные новые хоткеи не добавлены.

## Магазин (0.12.0)
Откройте «Магазин» в главном меню. Для тестовой покупки добавьте stones через Alt + Shift + = (по 100 за нажатие), затем нажмите «Купить» и «Выбрать». Если фокус в выпадающем списке, сначала кликните вне него — хоткеи в полях ввода отключены. Палочка и котёл выбираются независимо. Купленные предметы и выбор сохраняются после перезагрузки. Вернуть стандартные цвета можно бесплатно; повторно платить за уже купленные предметы не нужно. Каталог и цены: src/static/shop.json.

## Слизень (0.13.0)
Alt + Shift + 3 (верхний ряд) — принудительно вызвать enemyslime во время миссии, независимо от списка разрешённых типов. Одновременно возможен только один слизень; он не занимает углы синих/жёлтых врагов. Вызов отключает награды за текущую отладочную попытку.

Кликните слизня и нарисуйте три жеста с карточек под ним — в любом порядке, каждый по одному разу. При верном касте соответствующая карточка исчезает; после всех трёх слизень исчезает. Золотая точка на рисунке показывает начало жеста. Образцы всех десяти жестов есть в обучении. Пока слизень в центре, ингредиенты и управление котлом заблокированы; таймер не останавливается.

## Защита кристалла (1.0.0)
| Клавиша/действие | Результат |
| --- | --- |
| Alt + Shift + P в меню/мастерской | Добавить в постоянное хранилище по одной бутылке frost, flame, echo, healing. Само добавление не помечает будущую арену как отладочную. |
| F9 на арене | Открыть/закрыть панель отладки: выбор любого типа врага и запуск любой волны 1–10. |
| Alt + Shift + 1 на арене | Вызвать fire (огненный куб). |
| Alt + Shift + 2 на арене | Вызвать frost (ледяной куб). |
| Alt + Shift + 3 на арене | Вызвать moss (мшистый слизень). В мастерской этот хоткей по-прежнему вызывает прежнего enemyslime. |
| P / кнопка паузы | Пауза и продолжение. Скрытие вкладки включает паузу автоматически. |
| F8 | FPS на арене. |
| Esc | Выход в меню; потраченные на вход зелья не возвращаются. |

Спавн врага и запуск волны через отладку отмечают текущую арену как debug: новые stones и карточки за неё не выдаются. Уже заработанное сохраняется. Переход через F9 очищает текущих врагов/очередь, восстанавливает кристалл до 100 HP и снимает его DoT; набор зелий заново не выдаётся. Спавн соблюдает maxConcurrent текущей волны. Для использования хоткея после выбора в select сначала уберите фокус из поля.

Для обычного входа: «Защита кристалла» → выбрать 3 разных зелья → «Играть». Каждое списывается сразу и доступно один раз в этой попытке. Каждая новая попытка оплачивается снова. Реальные зелья добываются четырьмя рецептами; соответствующее зелье видно в меню и на экране победы.

Управление: выбрать врага кликом, затем жест (огненный — квадрат/2, ледяной — V/1, мшистый — Z/6). Выбрать кристалл и применить квадрат для снятия горения, V для снятия заморозки. Лечение: нажать зелье на нижней панели, затем кристалл. Остальные бафы активируются нажатием на зелье и действуют на последующие правильные попадания. Между волнами «Дальше» сохраняет очки; выбранная монетка + любой жест запускает риск ×2/обнуление и автоматический переход. Stones и карточки монетка не затрагивает.

Конфиги: src/static/defense.json, potions.json, cards.json. Описания и имена — src/translate/*.json.

В 1.0.1 арена использует исходные Hand/Wand и те же эффекты варки. Настройки цветов/частиц и нового позиционирования arenaRig — src/static/spellEffects.json. Для проверки вспышки выберите врага и нарисуйте правильный контржест либо выберите кристалл и скастуйте V/квадрат. На выбранную монетку действует любой распознанный жест. Повтор того же жеста повторяет эффект. Новые хоткеи не добавлены.

## Общий хват (1.1.0)
В обоих режимах поводите курсором по горизонтали/вертикали, резко смените направление и остановитесь: рука и палочка должны двигаться вместе, без зазора в точке хвата. Частицы остаются на кончике. Для настройки ощущения движения используйте handRig в src/static/spellEffects.json: tracking.frequency/aimDamping/rotationDamping, velocityTilt и параметры sway. Для позиции хвата — grip/gripRotation/gripDepth. Новые хоткеи не добавлены.

## Распознавание (1.2.0)
В свободной игре V/Λ/Z/L/W можно рисовать с наклоном примерно до 35°. Квадрат и круг допускают произвольный угол, другое место начала и обратное направление. Прямые линии по-прежнему различаются по направлению: допуск около 20°, чтобы вертикаль не подменялась диагональю. Быстрое рисование и паузы внутри жеста поддерживаются; неполный или неоднозначный рисунок может не засчитаться.

Для проверки выберите котёл и нарисуйте наклонённый V (огонь усиливается), затем наклонённый квадрат (ослабляется). На арене выберите огненного врага и используйте наклонённый квадрат. Поверните/измените размер окна — форма не должна сплющиваться и переставать распознаваться. В обучении остаётся строгая обводка образца с золотой точки. Допуски и чувствительность настраиваются в src/static/gestureRecognition.json. Новых хоткеев нет.

В 1.2.1 свободное рисование дополнительно допускает маленький случайный хвостик у начала/конца, короткий зазор замыкания круга/квадрата и неровные вершины W. Это не позволяет пропускать целые стороны или подменять L прямой. Дополнительные параметры endpointTrim*, closurePathRatio/closureMaxSpanRatio и elastic* находятся в том же JSON. Обучение по-прежнему требует обводить полный образец; новые хоткеи не добавлены.

## Новая варка и качества (1.4.0)
Первый вход в новом профиле автоматически даёт по одному добротному зелью каждого из четырёх рецептов, без stones. Это однократный набор; удалять сохранение для обычной игры не требуется. У существующего профиля бонуса нет. F10/Alt+Shift+P по-прежнему добавляют по одному зелью, теперь качества fine.

Подъём: кликните цветной куб и нарисуйте вертикальную линию (3), либо используйте прежний Alt+Shift+L после выбора куба. Под ним появится горизонтальная руна сброса (4). Выбор котла/врага тоже отпускает куб. После успешного внесения куб возвращается на своё место. Метки цветов рецепта помогают выбрать нужный куб.

Поджиг: выберите котёл, нарисуйте V (1); подсказка под котлом исчезнет навсегда после первого усиления огня. Охлаждение — квадрат (2). Помешивание — круг (5) по выбранному котлу: +25 к шкале, максимум100; она постепенно снижается. Нужный диапазон виден в HUD. Котёл покачивается во время помешивания. При ошибочном диапазоне внесение ингредиента штрафуется; выведите куб из котла, исправьте помешивание и повторите.

В конце честной победы цилиндр-зелье показывает качество обычное/добротное/мастерское по1/2/3 звёздам и добавляется в соответствующую ячейку постоянных запасов. Отладочная победа показывает образец без выдачи. Старые запасы мигрируют в добротные. Для входа на арену сперва расходуются обычные бутылки, потом добротные, потом мастерские. Новых хоткеев в1.4.0 нет; все прежние сохранены.

Оформление меняется в src/static/theme.json; параметры варки — brewing.json и missions.json (stirring и stages[].stirring).

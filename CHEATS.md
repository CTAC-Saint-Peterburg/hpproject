# Отладка и управление
Версия 0.12.0. Клавиши работают по физическому коду независимо от раскладки, без повтора при удержании. В полях ввода отключены.

| Клавиша | Действие |
| --- | --- |
| F8 | Переключить FPS: цифры в чёрном квадрате. Измеряется в 3D-сцене; в меню последнее значение. |
| Alt + Shift + = | Добавить 100 stones, также в меню. |
| Alt + Shift + - | Вычесть 100 stones, минимум 0. |
| Alt + Shift + ↑ | Усилить огонь на 1, максимум 3. |
| Alt + Shift + ↓ | Уменьшить огонь на 1, минимум 0. |
| Alt + Shift + L | Включить левитацию без жеста. |
| Alt + Shift + N | Пропустить этап; награды, рекорды и достижения отключаются до следующей попытки. |
| Esc | Прервать миссию и выйти в меню. |

Обычное управление: клик по котлу выбирает его. V-жест (1) усиливает огонь, замкнутый квадрат (2) ослабляет. Температура меняется постепенно. Вертикальный жест (3) включает перенос: кликните бутылку и подведите к центру котла. Для повторной попытки выведите бутылку из зоны и внесите снова.

Старые + / - для перемотки рецепта отключены.

## Вызов врагов (0.8.0)
| Хоткей | Действие |
| --- | --- |
| Alt + Shift + 1 (верхний ряд) | Вызвать синего enemycold. |
| Alt + Shift + 2 (верхний ряд) | Вызвать жёлтого enemyfire. |

Только во время активной миссии. Можно вызвать любой тип независимо от конфига уровня. Одновременно максимум два врага; если оба угла заняты, сначала уничтожьте одного. Успешный принудительный спавн помечает попытку как отладочную: stones, рекорды и достижения за неё не начисляются. Новая попытка снимает эту отметку.

Выберите врага кликом (белая обводка), затем нарисуйте V против синего или замкнутый квадрат против жёлтого. Попадание снаряда изменяет температуру на −15/+15 °C.

## Обучение (0.9.0)
Открывается кнопкой «Обучение заклинаниям» в меню. Обведите образец от золотой точки по стрелке, не отпуская кнопку мыши/палец. Успешный рисунок засчитывается после отпускания. Нужно по два повтора каждого из десяти жестов. Прогресс сохраняется; «Очистить» стирает только текущий рисунок. Прохождение необязательно: можно сразу играть. Отдельные читы для прогресса обучения не добавлены.

## Языки (0.10.0)
Меню → «Язык»: русский, English, 中文, Español, Français. Переключение не сбрасывает прогресс; выбор сохраняется после перезагрузки. Горячие клавиши одинаковы во всех языках и раскладках. Словари находятся в src/translate/*.json. Отдельного хоткея для смены языка нет.

## Эффекты (0.11.0)
Рисуйте жесты в игре: каждый распознанный жест меняет след палочки и создаёт цветную вспышку. Выберите котёл для вспышки на котле либо врага и примените правильное контрзаклинание для вспышки на враге. Повтор того же жеста повторяет эффект. Alt + Shift + L позволяет проверить эффект левитации без рисования. Параметры цветов, скоростей, количества, времени жизни и вспышек: src/static/spellEffects.json. Отдельные новые хоткеи не добавлены.

## Магазин (0.12.0)
Откройте «Магазин» в главном меню. Для тестовой покупки добавьте stones через Alt + Shift + = (по 100 за нажатие), затем нажмите «Купить» и «Выбрать». Если фокус в выпадающем списке, сначала кликните вне него — хоткеи в полях ввода отключены. Палочка и котёл выбираются независимо. Купленные предметы и выбор сохраняются после перезагрузки. Вернуть стандартные цвета можно бесплатно; повторно платить за уже купленные предметы не нужно. Каталог и цены: src/static/shop.json.

### Повторная сборка

Использовать `android:build`, а не просто Build в Studio после редактирования JS. Studio использует последний каталог из `hyped-web-assets.path`. После Gradle Clean каталог generated может исчезнуть — повторно выполнить android:build. Не удалять резервные копии автоматически. Сценарий обновляет только перечисленные в шаблоне native-файлы; перед будущими ручными интеграциями сверять шаблон с проектом.

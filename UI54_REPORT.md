# UI54 — Android-поворот и читаемость, 28.11.2026

Версия5.10.0 / Android versionCode6000, ветка android-port-5.5.0. Stable-v5.5.0 не перемещалась. Это новые разрешённые UI-правки и изменение скорости врагов, не новая стабильная версия.

## Что изменилось

1. Android: WebView вложен в FrameLayout. Insets системных панелей/вырезов применяются к внешнему контейнеру, поэтому реальный viewport игры меньше экрана. На API30+ учтены обязательные системные жесты; на24–29 используются прежние systemWindowInsets, на28+ дополнительно safeInsets выреза. Insets запрашиваются повторно после смены конфигурации. В браузере — viewport-fit=cover и env(safe-area-inset-*).
2. `ScreenOrientation` выбирает режим по `isGameplayScreen`: меню, обучение, подготовка, награда/поражение — portrait; активная варка, защита, её пауза и промежуток с монеткой — landscape. Native-интерфейс HypedDisplay принимает только эти два значения и проверяет текущий локальный URL. Стартовая ориентация portrait, игровая sensorLandscape (обе стороны). Прежняя подсказка поворота и переводы сохранены, ROTATE_HINT_ENABLED=false; автоматическая пауза от этой подсказки тоже отключена.
3. Manifest обрабатывает orientation/screenSize/smallestScreenSize/keyboardHidden. onConfigurationChanged обновляет insets, не вызывает loadUrl и не заменяет WebView/store. Это исправление именно смены ориентации; сохранение живого раунда после убийства процесса Android не добавлялось.
4. Во внешнем браузере Screen Orientation API вызывается по возможности; браузер может отказать вне fullscreen. В таком случае меню всё равно получает портретную область шириной не более72% высоты, игровая сцена — прежний landscape-fit с полями. Это не обещание физической блокировки любого браузера/планшета. На целевых Android-телефонах ориентацией управляет Activity.
5. Книга арены теперь высотой64–100 CSS px, герб56–90px, пропорционально высоте кадра. Размеры3D и hit area согласованы с расстоянием до камеры. Центры подняты, перенесены немного вперёд от стены. Пауза — жёлтый rune, 24–40px, по центру, opacity1→.7→1 за2.4с; reduced-motion отключает пульсацию.
6. При удержании книги3с рядом возникает SVG-кольцо примерно90% высоты книги, без заливки, с цифрой внутри. Прогресс рисуется плавно за3с. Отпускание, уход указателя, blur/visibility отменяют действие как раньше. Статического текста «Зажать3с» больше нет; доступное название кнопки сохранено.
7. ResultPanel общий для обоих финальных экранов. Награда/бутылка/кнопки компактнее, портретный режим даёт больше высоты. ResizeObserver подгоняет весь блок только если естественная высота всё ещё не помещается (длинный перевод, маленькое окно), без прокрутки и без скрытых кнопок.
8. Враги визуально ещё×1.15: общий множитель1.3225 относительно исходных моделей. Grounding и подсказки уже используют общий множитель. Базовые speed всех8 типов в defense.json умножены на.85, у летунов angularSpeed тоже×.85; время атак/снарядов, HP, награды и размер в store не менялись.
9. Содержимое селекта языка центрировано. Выбор миссии занимает всю ширину блока действий. Его полное значение рисуется отдельным переносящимся текстом; сверху прозрачный нативный select сохраняет мобильный выбор/клавиатуру/доступное имя. Минимальная высота64px, длинный текст увеличивает высоту, пагинация измеряет реальный блок.

## Проверки и ограничения

- ESLint изменённых JS/JSX прошёл. 287 Node-тестов прошли: добавлены состояния ориентации и геометрия увеличенных кнопок в кадре/перед стеной; существующий тест проверяет увеличенные тела/обводки над столом, перенос и игровой баланс покрыты прежними тестами.
- Web Vite и Android Vite/Gradle собираются. Финальный APK и SHA — mobile/PORT_STATUS.md.
- На28.11 ADB не видит устройств. CUA возвращает отсутствие native pipe/browser host. Скриншоты пользователя относятся к5.9.1; они не являются приёмкой5.10.0. Новый APK пока не установлен/визуально не проверен.

## Следующий ручной прогон

- Установить5.10.0 поверх прежнего APK без очистки профиля. Проверить язык, баланс и покупки.
- Повернуть телефон в главном меню в обе стороны: меню portrait, шапка/кошелёк ниже статус-бара, нижние кнопки выше жестовой полоски. Проверить Android10 и современный аппарат с вырезом; жестовую и трёхкнопочную навигацию.
- Запустить варку/защиту: автоматический landscape. Повернуть на другую сторону, затем обратно — текущая миссия/волна/враги/HP/таймер не сбрасываются. Проверить фон→возврат и штатную паузу.
- В защите: обычный короткий клик книги ничего не делает; удержание рисует круг3→2→1, отпускание на2с отменяет, полные3с открывают portrait-меню. Герб, книга и кольцо не перекрываются с HUD и не входят в стену.
- Завершить и проиграть варку, включая длинное название зелья и debug-сообщение; оба действия доступны без прокрутки. Повторить с каждым из5 языков. Проверить «Повторить» → landscape и «В меню» → portrait.
- Выбрать длинную миссию: весь текст виден, системный список открывается на всю площадь кнопки. Проверить пагинацию после смены языка/ориентации.

## Основания native-решения

По умолчанию изменение конфигурации может пересоздать Activity; ручная обработка выбранных изменений оставляет ответственность за переразметку приложению: [Android — configuration changes](https://developer.android.com/guide/topics/resources/runtime-changes). Insets для системных панелей/вырезов предназначены для защиты интерактивного контента от перекрытия: [Android — edge-to-edge](https://developer.android.com/develop/ui/views/layout/edge-to-edge).

## Назначение и ограничения

Это игра с распознаванием нарисованных заклинаний: варка зелий и защита кристалла. Есть магазин, экипировка, зелья разного качества, достижения, обучение, локальный профиль, пять языков, звук и touch-управление.

Владелец предпочитает лёгкие low-poly модели из примитивов, моноцветные материалы, переиспользование эффектов и компонентов. Нельзя добавлять тяжёлые модели/текстуры или менять UI без поручения. Hyped Pot не переводится.

**5.5.0 — стабильная игровая база по решению владельца.** Commit `4ee9b47`, tag `stable-v5.5.0`. После неё Android-перенос продолжен отдельно: `af580cd`, `b96103a`, ветка `android-port-5.5.0`. Это исторические ориентиры, не команда переключиться или откатить текущую ветку.

Стабильность веб-базы не равна готовности Android. Последнее сообщение владельца: на бюджетном телефоне с Android 10 после загрузки остаётся фон. Причина пока не установлена. См. ANDROID_HANDOFF.md.

## Технологии

React 19, JavaScript/JSX, Vite 8; Three.js 0.184 / React Three Fiber / Drei, WebGL 2; Zustand persist/localStorage; i18next; Web Audio/OGG; SVG/Canvas2D/Pointer Events. Установлены также MUI/Emotion. Полные версии — package.json, фиксация зависимостей — yarn.lock v1.

Native: Kotlin Activity, системный Android WebView, AndroidX WebKit/WebViewAssetLoader, Gradle. Игра не переведена на Unity: Unity LevelPlay рассматривается только для будущей рекламы. Firebase/реклама пока **не реализованы**.

## Важные договорённости

- До изменения интерфейса читать `UIdata.md`; после обновлять описание, таблицы и затронутые снимки CSS. Документ описывает код, не навязывает устаревший макет.
- Данные профиля: localStorage `hpproject-save-v1`, версия формата не должна меняться без миграции. Сохраняются stones, покупки, экипировка, зелья по качествам, достижения, обучение, рекорды и карты. Постоянные покупки сериализуются как 0/1. Активный раунд после уничтожения процесса не восстанавливается.
- В защите кристалла временные stones ещё не являются постоянным балансом. Не обходить существующие правила зачисления/потери при наградах и синхронизации.
- У всех 11 зелий есть характеристики по качествам basic/fine/masterwork. Их значения, цены и рецепты описаны в `POTIONS_BALANCE.md`; не подменять эффект качества только визуальным цветом.
- Обучение: каждое из 10 заклинаний успешно повторяется дважды. Достижение training и 1000 stones выдаются один раз; повтор/перезагрузка не должны выдавать награду снова.
- Системный язык выбирается только при отсутствии сохранённого предпочтения; ручной выбор приоритетнее. Поддерживаются ru/en/zh/es/fr, резервный en. Старое сохранённое ru нельзя достоверно отличить от ручного — не удалять автоматически.
- Читы могут запрещать награды попытки. Не подключать debug-профиль к будущей подтверждённой сервером экономике.
- Последние 271 тест и обе сборки прошли в предыдущей работе; это исторический результат, не обещание результата на другой машине.

# ESLint: указать реально изменённые файлы
